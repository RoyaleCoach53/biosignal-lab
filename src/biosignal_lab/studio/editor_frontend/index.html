Connections and keyboard instructions

Choose an output button, then an input button to connect. A new link replaces the existing input connection. Shift-click or Control/Command-click node titles to select multiple nodes. Tab to a node title and use arrows to move selected nodes; Shift moves faster. Delete removes the selection. Control/Command+A selects all; Control/Command+C copies the selection inside this editor; Control/Command+V pastes it with new IDs and only internal connections; Control/Command+G groups selected nodes and Shift+Control/Command+G ungroups them. Escape cancels a pending connection and clears selection. Control/Command+Z undoes a graph edit; Control/Command+Shift+Z redoes it. Focus the canvas and use arrows to pan, plus/minus to zoom. The connection list supports deletion without a pointer. Groups are visual metadata; Python executes the scientific graph unchanged.
