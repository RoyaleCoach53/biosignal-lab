Connections and keyboard instructions

Choose an output button, then an input button to connect. A new link replaces the existing input connection. Tab to a node title and use arrow keys to move it; Shift moves faster. Delete removes the selected node, Escape cancels a pending connection. Control/Command+Z undoes a graph edit; Control/Command+Shift+Z redoes it. Focus the canvas and use arrow keys to pan, plus/minus to zoom. The connection list below supports deletion without a pointer. Scientific validation and execution happen in Python.
