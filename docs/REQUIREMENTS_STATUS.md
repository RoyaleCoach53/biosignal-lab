- **Implemented**: an inspectable callable implementation exists in the cited
  source. This alone is not a verification or completeness claim.
- **Automated verified**: cited tests or recorded measurements exercised the
  stated scope. Historical and workstream results do not prove a later combined
  tree passed; check report source hashes and the integration checkpoint.
- **Partial**: a usable subset exists, with remaining requested behavior listed.
- **In progress**: source under development; final review/tests/integration pending.
- **Not implemented**: no completed implementation was identified for the named
  requirement. A dependency, document, interface control or generic primitive
  does not count as the missing feature.
- **External gate**: physical equipment, independent people, external accounts,
  authorization, or maintainer approval is required. These gates do not excuse
  unfinished software work listed below.
