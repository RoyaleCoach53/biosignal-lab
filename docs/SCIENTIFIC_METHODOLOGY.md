# Scientific methodology

The implemented formulas, units, filter defaults, frequency bands, import rules,
and limitations are documented in [METHODS.md](METHODS.md).

The executable [benchmark protocol](../benchmarks/README.md) records analytical
targets and predeclared tolerances. See [current measurements](VERIFICATION_RESULTS.json)
and the [release audit](SCIENTIFIC_AUDIT.md) for evidence.

This is numerical engineering verification with AI-assisted review. It is not
external peer review, validation on human recordings, or clinical validation.
